# Learning Path DevEx / GenAI / Agentic Interview Prep

This repository contains a zero-build static application that presents a complete interview-preparation learning path for a Principal Software Engineer role focused on:

- GenAI for software development
- Agentic AI systems
- Developer Experience and platform engineering
- Engineering excellence and organizational impact

## Run locally

Open the application directly:

- `/home/runner/work/learningpathdevexiaagenticfordev/learningpathdevexiaagenticfordev/index.html`

Or serve it locally:

```bash
cd /home/runner/work/learningpathdevexiaagenticfordev/learningpathdevexiaagenticfordev
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## What is included

- A 16-week structured learning path
- Curated current resources for GenAI, agent systems, DevEx, and engineering excellence
- Hard module quizzes with scoring and explanations
- A global assessment aligned to Principal-level expectations
- An application plan describing the product, architecture, and roadmap for scaling this into a fuller training platform

## Notes

- The app is dependency-free and uses browser `localStorage` to persist quiz scores and completion status.
- There is no existing test infrastructure in this repository, so validation is done through direct browser verification and JavaScript syntax checking.
